# World Rivers (web tiles)

XYZ map tiles (zoom 0-7, JPEG) of a world rivers map made in QGIS, with a MapLibre GL JS viewer (`index.html`): a 3D globe with a 2D/3D switch (`#globe` / `#flat` in the URL).

Live: https://yperikov.github.io/world-rivers-tiles/

Data: [Natural Earth](https://www.naturalearthdata.com/) (public domain).
